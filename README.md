# 💳 TravelIN – Fintech for Foreign Travelers in India  

**Spend in India with Ease | Secure | RBI-Aligned**  

A demo fintech platform built for international visitors to India.  
Submit your visa, receive a temporary virtual INR debit card, and make payments or withdraw cash at official exchange rates.  

---

## 🚀 Live Demo  
🔗 [Open the TravelIN Website](https://amansingh080705.github.io/travelin-demo/)  

---

## ✨ Features  
- 🛂 Visa-based secure login & verification  
- 💳 Temporary **virtual INR debit card**  
- 🔄 Currency conversion at **official RBI-aligned rates**  
- 🏦 Cash collection from partnered banks  
- 💰 Wallet top-up with live conversion  
- 🌍 Currency list with flags, search, and filter  
- 📱 Responsive, modern UI
